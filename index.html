How it works

Three steps between you and a fresh operating system.

STEP 1

Create the USB pen

On any Linux PC run sudo bash installer.sh and pick your pen. It checks the project and builds the bootable drive for you.

STEP 2

Boot any computer

Plug the pen in, boot from it (BIOS or UEFI), and Alpine Linux loads into RAM. The menu appears automatically.

STEP 3

Search & download

Type part of an OS name, pick a result, and the ISO downloads to RAM with a live progress bar. Mount it and run the installer right away.

FAQ

Quick answers to common questions.

Do I need an OS on the computer to use OSFinder?

No. That's the whole point — OSFinder boots from USB and works on completely empty machines.

Where does the ISO get saved?

To RAM (/tmp). Nothing is written to the pen or the target disk unless you choose to copy the ISO to the pen.

What if there's no internet?

OSFinder tries ethernet automatically, then guides you through the WiFi wizard. Networks you connect to are remembered on the pen.

How much RAM do I need?

Enough for the ISO size while downloading — 8 GB is comfortable, 16 GB recommended for large ISOs.

Can I add an OS to the list?

Yes — the list is a public JSON file in the repository. Anyone can contribute to it.
